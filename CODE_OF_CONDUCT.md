# Code of Conduct

This project is committed to providing a welcoming and inclusive experience for everyone.

## Our standards

Examples of behavior that contribute to a positive environment include:

- Being respectful and constructive in discussions
- Giving and receiving feedback graciously
- Focusing on the problem rather than attacking the person
- Helping newcomers learn the project and its conventions

Examples of unacceptable behavior include:

- Harassment, insults, or discriminatory language
- Personal attacks or trolling
- Publishing private information without permission
- Repeated disruption of discussions or contributions

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, or pull requests that violate this code of conduct.

## Reporting

If you experience or witness unacceptable behavior, please contact the maintainers through GitHub issues or by opening a private discussion.
